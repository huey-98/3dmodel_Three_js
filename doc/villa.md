# 豪华别墅

入口 `src/scenes/villa/`。这是项目里唯一同时包含建筑、室内、地形和载具的场景。玩家角色是鲸尾女仆，出生在 `(4, 0, 12)`，镜头初始在 `(19, 12, 33)`。

## 操作

页面左上角提示与代码一致：

| 键 | 作用 |
| --- | --- |
| WASD / 方向键 / Shift / 空格 | 与[架构文档](./architecture.md)相同。船上时 WASD 和方向键改成划船，空格无效 |
| F | 屋外靠近门：开关门。靠近靠岸的船：走到登船点再上船。在船上：下船 |
| G | 门开着且人在门口附近：自动走到门内或门外，并切镜头 |
| 鼠标 / 滚轮 | 旋转与缩放。屋内距离被限制，避免穿墙 |

底部提示条 `#prompt` 按状态切换文案：上船、下船、开门、进门、出门，或「门已关闭，无法离开」。左上角 `#floor` 显示 `1F` / `2F` / `3F`。

## 模块

| 文件 | 职责 |
| --- | --- |
| `main.js` | 场景、输入、碰撞、楼层高度、自动行走、划船、镜头跟随 |
| `building.js` | 外立面、门窗、楼板、楼梯、门动画，并导出碰撞与楼层常量 |
| `villaMaterials.js` | 石材、大理石、木地板、地毯等 canvas 贴图，以及黄铜、玻璃材质 |
| `interior.js` | 三层家具、窗帘、吊灯、壁炉火焰 |
| `environment.js` | 草地、河、桥、公路、树石花草 |

`main.js` 把建筑、室内、环境依次加入场景，再在 `(7.5, WATER_Y, 22.2)` 放一条船。

## 建筑尺寸

定义在 `building.js`：

- 外墙宽 16（X）、深 12（Z）、厚 0.3，共 3 层，层高 `FLOOR_H = 4.2`
- 占地 `BUILDING_FOOTPRINT`：X ∈ [-8, 8]，Z ∈ [-6, 6]
- 室内 `INTERIOR` 各边内缩一个墙厚
- 正门宽 1.8、高 2.5，位于前墙（+Z）中央
- `DOOR_ANCHOR` 在门外 `(0, 0, 7.2)`；`INSIDE_POINT` Z = 4.2；`OUTSIDE_POINT` Z = 8.6

外立面是石材贴图，朝室内的那一面是石膏。窗、落地窗、气窗和门侧亮子记在 `OPENINGS` 里，种类有 `window`、`french`、`door`、`transom`、`sidelight`。沿墙位置字段是 `along`。玻璃和窗框由 `addGlazing` 按 `along` 摆放；一层前后窗台有花。墙体网格由 `addPiercedWall` 按这些洞的高度切成横条，实际开洞结果见文末「实现注意」。

一层正门是左右两扇，枢轴在门洞两侧。`setDoorOpen` 把目标开合设为 0 或 1，`update(dt)` 把当前角度平滑到目标，左右扇各转到约 ±1.38 弧度。室内点光源随开门变亮。

正立面还有勒脚、层间腰线、铜檐、门头三角楣、四根门廊柱、两层玻璃栏杆露台、门口石铺地、两侧石瓮和树篱。门廊柱、石瓮和树篱写进了 `WALL_RECTS`，会挡住人。露台没有行走高度，人在露台的水平位置上仍按室外地面高度走，从露台下方经过。屋顶是压扁的四棱锥石板瓦，顶尖铜球，两座烟囱。

楼板：一层地面是大理石。二层楼板用胡桃木，三层用拼花，都在对应楼梯井处切开，井口有木边和黄铜栏杆。三层天花是石膏板。每层墙裙约 0.96 高，前墙在门或落地窗处留空。

## 楼梯

两跑直梯，每跑 22 级，宽 1.5，跑长 6.2，靠后墙但留出 `STAIR_CLEAR_Z = 0.9`：

- 1F→2F 在室内左侧
- 2F→3F 在室内右侧

`stairSurfaceY` 按当前踏步取顶面高度，不是连续斜坡。`STAIR_WELLS` 只在踏步接近上层楼板的一段开口，避免整段楼梯把楼板划穿。

`main.js` 的 `resolveGroundY` 规定怎么踏上楼梯：人必须已经在这段楼梯上，或者从本层底部（进度 &lt; 0.22）或顶层（进度 &gt; 0.78）踩上去。这样一层走进楼梯上端时不会被直接抬到二楼。离开楼梯时，进度 ≥ 0.5 落到上一层，否则落回下一层。到室外则楼层归零，高度改由桥面决定。

楼梯两侧有栏杆碰撞 `STAIR_RAILS`，只在相连的两层、或人正走在这一跑上时生效。上层楼梯井在没走楼梯时会挡住（进度 &lt; 0.82），防止从井口踏空掉到楼下。走楼梯时不检测家具，避免人被踏步旁的柜子卡住。

## 室内陈设

`interior.js` 的家具按楼层挂在三个 Group 上，Y 分别是 0.04、`FLOOR_H`、`FLOOR_H * 2`。会挡路的家具调用 `solid(floor, x, z, hx, hz)` 写入 `FURNITURE_RECTS`。旋转过的沙发用 `footprint` 把局部半宽换成世界 AABB。餐椅不单独写入碰撞；一层和三层餐桌的矩形把椅位包在里面。

- **一层**：门厅铜环、会客厅地毯、绿色沙发和两张翼椅、大理石茶几、壁炉、座钟、长方形餐桌（圆柱底座）和五把餐椅、餐边柜、玄关条案和镜子、盆栽、三盏吊灯。窗帘为绿色。
- **二层**：主卧。床、两只床头柜、床尾凳、书柜、梳妆台、一张翼椅、一盏吊灯。窗帘为香槟色。
- **三层**：书房和休息室。壁炉、对称书柜、皮沙发、书桌和台灯、小会议桌和四把餐椅、地球仪、边柜、两盏吊灯。窗帘为深红色。

窗和落地窗按 `OPENINGS` 的 `along` 在室内挂窗帘和窗纱。壁炉火焰是点光源，`update(t)` 用两个正弦叠加闪烁。

## 外部环境

`environment.js`：

- 地面约 260×260，中间挖出河道。河北岸 `RIVER_Z0 = 20`，河南岸 `RIVER_Z1 = 36`，水面 `WATER_Y = -0.35`。河床在水面下，河岸放在河道内侧，避免和草地共面闪烁。
- `waterHeight(x, z, t)` 是两列正弦波。水面网格和船体的上下位置都用这个函数。船的横摇、纵摇是另外的正弦，不取波面倾角。
- 别墅门到河北岸有石子小路。较小的 Z 是北。木桥面高 `deckY = 2`，北引桥 Z 从 15.5 到 19.5，主桥面到 36.5，南引桥到 40.5，桥面半宽 1.8。`ENV_RECTS` 含桥面宽度以外的整段河面，以及桥两侧栏杆。人不能走进河里。桥墩在桥面两侧，中间留出航道；`PIER_RECTS` 只挡船，不挡行人。
- 河南岸外侧 Z = 48 有一条东西向公路，南引桥尽头有短岔路接上。
- 石头、草丛、花用 `InstancedMesh`，树木和灌木是独立网格。`isReserved` 避开建筑周边、河道、桥、小路和公路，装饰物不生成在这些地方。装饰物本身没有碰撞。

人在室外的高度由 `bridgeHeight` 决定：引桥段按 Z 在 0 和 `deckY` 之间线性插值，主桥面为 `deckY`，其余为 0。

## 主循环里的状态

人物不在船上时：

1. 若自动路径还有点，以速度 2.4 走向下一个点，距离 &lt; 0.18 视为到达。玩家按下移动键会清空路径并取消完成回调。
2. 否则按键移动，速度 3.5，Shift 为 7。位置夹在 [-100, 100]。
3. `resolveGroundY` 得到地面高度。着地时 Y 以系数 `min(dt * 18, 1)` 跟上地面，所以上楼梯是贴着踏步走，而不是瞬移。离地时 Y = 地面高度 + 跳跃偏移。跳跃偏移只在离地期间积分，落地归零。

碰撞体 `SOLIDS` 是 `WALL_RECTS` 加 `ENV_RECTS`。前者含外墙、门廊柱、石瓮和树篱；后者含桥宽以外的河面和桥侧栏杆。另外还有：当前楼层适用的楼梯栏杆、门洞、楼梯井、当前楼层家具。门洞在二层及以上永远挡住（那是过梁）；一层只在门关着时挡住。门开着时人可以自己走过门洞。

F 的优先级：在船上且交互锁定结束 → 下船；否则与登船点的水平距离小于 2.4 → 自动走到登船点再上船；否则在一层屋外、与 `DOOR_ANCHOR` 的水平距离小于 3.6 → 切换门的开关。屋内按 F 不会关门，避免把人关在里面。人不在船上、人在一层、与 `DOOR_ANCHOR` 的水平距离小于 3.6、且门已开时，G 会自动走进或走出。走到终点后才改镜头：进屋偏移 `(-3.4, 2.6, -4.4)`，出门偏移 `(4, 4, 5)`，都相对人物位置。自己走进去时，室内距离限制仍会按位置生效，镜头保持原来的轨道偏移。

## 划船

上船把人物从场景根节点挪到船的子节点，座位用 `boat.seatPosition`，朝向局部 π。下船要求船靠岸：船的 Z 距北岸或南岸小于 2.5 时，在岸上沿 X 找一个不被挡住的点。离岸更远时 `boatDock()` 返回空，提示必须划到岸边。交互锁定是上船 0.45 秒、下船 1 秒，避免同一个 F 立刻反向操作。

船上：

- W / 上 加速，S / 下 减速或倒车。加速度 3.8，每帧阻尼，速度限制在 [-1.8, 4.5]。
- A / 左、D / 右 转向。有速度时转向跟随船头方向（倒车时舵反向），几乎静止时仍可转向。角速度约 0.95 弧度/秒。
- 位移沿 `sin(heading)`、`cos(heading)`，也就是船头 +Z 转到 `boatHeading` 后的方向。
- `boatBlocked`：不能开出河道两端（各留 1.15），|X| 不能超过 78，并且要避开桥墩（X 方向垫 0.5，Z 方向垫 1.55，大约是船体半宽和半长）。撞到障碍时沿单轴滑，并额外衰减速度。
- 有油门或速度绝对值 &gt; 0.18 时推进划桨相位，调用 `boat.setRowPhase` 和女仆的划船 `update`。

## 镜头

室外：距离 3–70。极角从 0（正上方）到 `π/2 - 0.03`（略高于水平）。

室内且不在船上：距离约 1.4–6.4；正在上楼梯时更近，约 1.7–3.4。极角从 0.16 到约 0.72π，室内可以从水平线以下看。然后沿当前视线把相机拉回房间盒子内。房间顶在普通楼层是本层天花下沿，上楼梯时抬到人头顶以上 2.55，避免相机被下层楼板夹进身体。不在楼梯上时，视线若打到本层家具，距离再缩短到碰撞点之前。

## 实现注意

`OPENINGS` 的沿墙坐标字段是 `along`。窗框、窗帘和 `poseOf` 都读 `along`。`addPiercedWall` 挖洞时读的是 `op.at`，对象上没有这个字段。和某个洞的高度重叠的横条会算成 `NaN`，这一整条墙（该墙的全长，不只是窗口那么宽）不会生成网格。玻璃仍按 `along` 放在窗位上。碰撞用的 `WALL_RECTS` 仍是整段墙（门洞除外），人不能从这些缺口穿过去。
