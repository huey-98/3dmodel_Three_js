# 鲸尾女仆

入口 `src/scenes/maid/`。这是角色观察页，不引入行走、碰撞或场景道具。角色由 [`createWhaleMaid`](./shared.md) 生成，直接放在场景原点。

## 画面

背景色 `#f4f7fb`，与页面浅色 UI 接近。地面是半径 2.4 的圆，材质 `ShadowMaterial`（不透明度 0.16），只接收阴影，用来托出脚底影子。

相机视野 32°，初始位置 `(0, 1.15, 3.35)`，看向 `(0, 0.95, 0)`，大约在角色胸口高度。近裁剪 0.1，远裁剪 50。

光照：

- 半球光，天色偏暖、地面偏冷，强度 0.85
- 主光在右前上方 `(2.4, 4.2, 3.2)`，强度 1.55，投射阴影，阴影相机框住角色附近
- 左侧冷色补光，强度 0.55
- 背后轮廓光，强度 0.45

色调映射曝光 1.12。

## 交互

只有轨道控制：

- 拖拽旋转，阻尼 0.08
- 距离限制在 1.4–6
- 极角最大约 0.72π，不能钻到地平面以下
- `autoRotate` 关闭

每帧调用 `maid.update(dt)`，不传 `moving` 和 `row`，所以角色保持站立：眨眼、头发微动、鲸尾轻摆、身体有很小的起伏。页面文案写明操作是「鼠标拖拽旋转、滚轮缩放」。

右上角「返回目录」链回首页。
