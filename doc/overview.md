# 项目概述

`3dmodel` 是一个纯前端的 Three.js 场景集合。没有后端、没有外部模型文件，几何体、贴图和角色都在运行时用代码生成。三个场景共用同一份 `three` 依赖，从根目录首页互相跳转。

版本 `0.1.0`，`"type": "module"`。运行时依赖只有 `three`（`^0.187.0`），开发依赖是 `vite`（`^8.3.8`）。

## 运行

```bash
npm install
npm run dev
```

开发服务器打开根目录 `index.html`，标题为「3D 场景」。三个入口：

| 卡片 | 开发地址 | 代码 |
| --- | --- | --- |
| 豪华别墅 | `/src/scenes/villa/` | 可进屋、上楼、划船 |
| 鲸尾女仆 | `/src/scenes/maid/` | 角色展示，可旋转查看 |
| 荒漠迷城 | `/src/scenes/bazaar/` | 绿篷棚子、沙黄大地砖、周围旧楼，棚下地面有红色 B |

生产构建：

```bash
npm run build
npm run preview
```

`vite.config.js` 把根目录 `index.html` 和每个 `src/scenes/<name>/index.html` 都列为 Rollup 入口，所以三个场景会打成独立页面。

## 场景在做什么

**豪华别墅**是唯一带完整玩法的场景。玩家控制鲸尾女仆在草地、桥面和三层别墅里走动，可以开门、自动走进门、上楼梯、在河边上船并沿河划行。碰撞用水平面上的轴对齐矩形，高度由楼层、楼梯踏步和桥面单独计算。

**鲸尾女仆**是同一套角色模型的观察页。角色站在浅色背景前眨眼、头发和鲸尾轻轻摆动，镜头用 `OrbitControls` 绕着看，没有行走。

**荒漠迷城**是可走动的街区。玩家控制一名持步枪的 CT 干员，从棚屋南侧走进敞开的绿篷棚，也可以从拱门进入东边沙黄楼里的小卖部。第一人称可以开火和换弹。棚内和小卖部的镜头距离被限制在房间盒子里，避免相机穿进周围建筑。

## 单位与朝向

场景单位按米使用。Y 轴向上。角色面向移动方向时，`rotation.y = atan2(move.x, move.z)`，也就是面朝世界 +Z。小船船头同样朝局部 +Z。
