# 项目概述

`3dmodel` 是一个纯前端的 Three.js 场景集合。没有后端、没有外部模型文件，几何体、贴图和角色都在运行时用代码生成。四个场景共用同一份 `three` 依赖，从根目录首页互相跳转。

版本 `0.1.0`，`"type": "module"`。运行时依赖只有 `three`（`^0.187.0`），开发依赖是 `vite`（`^8.3.8`）。

## 运行

```bash
npm install
npm run dev
```

开发服务器打开根目录 `index.html`，标题为「3D 场景」。四个入口：

| 卡片 | 开发地址 | 代码 |
| --- | --- | --- |
| 豪华别墅 | `/src/scenes/villa/` | 可进屋、上楼、划船 |
| 鲸尾女仆 | `/src/scenes/maid/` | 角色展示，可旋转查看 |
| 荒漠迷城 | `/src/scenes/bazaar/` | 绿篷棚子、沙黄大地砖、周围旧楼，棚下地面有红色 B；可选自由跑图或波次防守 |
| 炙热沙城 | `/src/scenes/dust2/` | CS2 Dust2 可跑图：三路（A 大 / 中路 / B 通），A 坑在 A 大东侧，开阔自杀位正对中门 |

生产构建：

```bash
npm run build
npm run preview
```

`vite.config.js` 把根目录 `index.html` 和每个 `src/scenes/<name>/index.html` 都列为 Rollup 入口，所以四个场景会打成独立页面。

任一场景地址后加 `?stats` 会在左上角显示性能面板，见 [architecture.md](./architecture.md)。2026-11-20 采集的各场景性能基线和别墅的 A/B 对比记在 [perf/baseline.md](../perf/baseline.md)。

## 场景在做什么

**豪华别墅**是唯一带完整玩法的场景。玩家控制鲸尾女仆在草地、桥面和三层别墅里走动，可以开门、自动走进门、上楼梯、在河边上船并沿河划行。碰撞用水平面上的轴对齐矩形，高度由楼层、楼梯踏步和桥面单独计算。

**鲸尾女仆**是同一套角色模型的观察页。角色站在浅色背景前眨眼、头发和鲸尾轻轻摆动，镜头用 `OrbitControls` 绕着看，没有行走。

**荒漠迷城**是可走动的街区。玩家控制一名持步枪的 CT 干员，从棚屋南侧走进敞开的绿篷棚，也可以从拱门进入东边沙黄楼里的小卖部，再经小卖部东墙的后门和一条带顶通道走到场地外的东侧空地。第一人称可以开火和换弹。棚内、小卖部和通道的镜头距离被限制在房间盒子里，避免相机穿进周围建筑。从目录页进入时会先选**自由跑图**或**游戏模式**：游戏模式是波次防守，按 G 开波，敌人从南侧凹槽和北面进场，清光一波回血回甲并补满备弹，随后下一波；阵亡后从当前波重开。

**炙热沙城**按 CS2 `de_dust2` 雷达走位还原：匪家在南、警家在北、B 西北、A 东北。匪家出发三条路——东下匪口穿两道金属 A 门上 A 大（坑在东侧）；北缘开阔自杀位落到中路，中门西进 B1、东经 Xbox / 小道楼梯上 A 小；西斜坡下后花园进 B 通。警家与沙地同层（-1.0），B 门短坡接入，B 窗可跳。玩家控制鲸尾女仆自由跑图，屏幕底部显示当前点位名，地址栏 `?spawn=` 可从 12 个点位出生。没有敌人与枪械。

## 单位与朝向

场景单位按米使用。Y 轴向上。角色面向移动方向时，`rotation.y = atan2(move.x, move.z)`，也就是面朝世界 +Z。小船船头同样朝局部 +Z。
