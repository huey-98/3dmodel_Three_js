# 炙热沙城二（Dust2）场景 · 中文点位雷达版

对应代码：`src/scenes/dust2/`。入口页 `index.html`，逻辑 `main.js`，世界在 `world.js` 与 `world/` 子目录。
场景是 CS2 经典地图 de_dust2 的可跑图还原：没有敌人与枪械，控制鲸尾女仆在多层地形上走动、跳箱、钻隧道。

布局按用户提供的**中文点位俯视雷达**重排（雷达朝向：匪家在南、警家在北、B 西北、A 东北、A 大/A 坑东缘、B 通/后花园西缘）。
层高沿用真实 `de_dust2.bsp`（GoldSrc v30）世界面片实测（`.tmp_ref/` 解析脚本），坐标架为 X 向东、Z 向南、Y 向上，
因此雷达的"上（北）"对应本代码 z 小、"下（南）"对应 z 大。

## 多层物理（physics.js）

- `groundAt`：只认不高于脚底 + `STEP_UP`+0.06 的最高板顶（楼下不被楼上抬走）。
- `blockedAt`：solid 全高挡人；platform 仅"顶高于脚底+余量 且 底低于膝盖"时挡人 → B 平台/沙地下可穿行，deep 板侧壁全高挡人。
- `STAIRS` 仅旋转楼梯切 ≤0.34m 踏步；其余坡道在 `RAMPS`，按 ≤0.12m 细踏步登记物理、视觉渲染平滑楔体（`rampMesh`），走感为斜坡。跳高约 1.5m。
- 木箱 `crate` 只登记顶面 platform：地面挡人作掩体、跳起可落箱顶（中门叉箱跳 A 小即靠此）。
- 脚底 < -6.2 坠出回出生点；`zoneAt` 同时匹配平面与脚底高度。

## 门与构件

`world/doors.js`：中门为半关闭木门（`halfClosedDoor`，东扇闭、西扇留缝），A 门为对开木门（半开可通行）；B 门/B 洞/B 通入口/电梯位/A 小楼梯/A 斜坡/A 坑口为 `archGate()` 石拱（旋转楼梯无门框）。
电梯位拱门朝 X 开口（x=20，警家侧入口）；B 通南口拱门门槛为后花园高度；A 平台西缘另有警家石拱门（x=26，框住电梯位下行口）。
警家木构拱廊（木柱 + `archSpandrel` 木拱楣 + 顶棚梁板）与北侧白楼立面在 `world/walls.js` 的 `ctSpawnArch()`；FRAGILE 白箱在 `world/props.js`；警家斜坡等坡道为 `world/floors.js` 的 `rampMesh` 平滑楔体。
A 包点北侧白楼立面（`kit.facade` 整面 + `archPane` 真实拱窗 + 阳台）与矮墙 A 字牌在 `world/walls.js` 的 `aSiteFacade()`。
城垛（匪家南面外圈墙、B 东墙、A 大东墙）与假窗在 `world/walls.js`，城垛都落在对应墙顶；B 门洞顶有过梁承城垛。包点喷图 A(35,16)、B(-23,16)。
雷达点位道具（大箱/高箱/矮箱/脚手架/卡车/蓝车/黄车/匪家蓝车/一箱/二箱/沙袋/叉箱/L 位/油桶/垃圾桶）在 `world/props.js`；
A 包点默认箱为 `tarpCrate`（木箱 + 蓝布盖），沙袋为 `sandbagStack`；
露天灯为落地灯柱，隧道/有顶段灯为吊灯。

## 出生点与镜头

`?spawn=`：t / garden / b2 / b / b1 / mid / midfar / ct / a / asmall / long / pit，共 12 个，全部带层高。
初始机位按出生点朝向生成（身后 6 米、抬高 4 米），室内出生点由房间夹取收回，不会卡进楼体。

## 验证方法

1. `npm run build` 通过。
2. Node 无头冒烟 `.tmp_ref/test_dust2.mjs`：12 出生点 `groundAt` 全命中期望层高。
3. 0.5m 多层 BFS（按 (格,高度) 记忆，落脚脚底=目标顶面后 `blockedAt`）：匪家出发可达全部 26 区域与 12 出生点
   （含中路缓坡/中门、暗道、B1/旋转楼梯/B 通、B 门/B 洞、电梯位/A 小楼梯、A 斜坡/A 坑、匪口）。
   改 `layout.js` 后务必重跑。
4. BSP 解析/对照脚本在 `.tmp_ref/`（`bspbase.mjs`、`fix_components.mjs`、`fix_world.mjs`、`fix_transect.mjs`、`fix_compare.mjs`）。
