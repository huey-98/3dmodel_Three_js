# 炙热沙城二（Dust2）场景 · CS2 走位版

对应代码：`src/scenes/dust2/`。入口页 `index.html`，逻辑 `main.js`，世界在 `world.js` 与 `world/` 子目录。
场景是 CS2 `de_dust2` 的可跑图还原：没有敌人与枪械，控制鲸尾女仆在多层地形上走动、跳箱、钻隧道。

布局按 CS2 官方雷达（匪家南、警家北、B 西北、A 东北）重排。坐标架为 X 向东、Z 向南、Y 向上，雷达的「上（北）」对应 z 小。
中门 / A 门 / B 门为金属对开；A 小只从中路上猫道；A 坑在 A 大东侧；B1 洞口正对中门与 Xbox。

## 多层物理（physics.js）

- `groundAt`：只认不高于脚底 + `STEP_UP`+0.06 的最高板顶（楼下不被楼上抬走）。
- `blockedAt`：solid 全高挡人；platform 仅「顶高于脚底+余量 且 底低于膝盖」时挡人 → 猫道在中路高度挡人，跳上 Xbox 后可落猫道。
- `STAIRS` 切 ≤0.34m 踏步（B1 旋转楼梯、警家 Cross）；其余坡道在 `RAMPS`，按 ≤0.12m 细踏步登记物理、视觉渲染平滑楔体（`rampMesh`）。跳高约 1.5m。
- 木箱 `crate` 只登记顶面 platform：地面挡人作掩体、跳起可落箱顶（Xbox 跳 A 小即靠此）。
- 脚底 < -6.2 坠出回出生点；`zoneAt` 同时匹配平面与脚底高度。

## 门与构件

`world/doors.js`：中门为半开金属门（`halfClosedDoor`，东扇闭、西扇留缝）；A 门为南端连续两道金属对开；B 门为东墙金属对开。B 窗是墙缺口，无门扇。B 洞 / B 通入口 / A 斜坡为 `archGate()` 石拱。
警家竹席顶木构拱廊在 `world/ctspawn.js`：东向木拱门对着 Boost 电梯位，北墙铁窗，悬挂灯，拱门外 FRAGILE 白箱（`world/props.js`）。
A 包点在 `world/asite.js`：北侧宫殿（青绿拱窗 + 阳台栏杆 + A 字牌）、A 大西墙药房（风化白墙、绿十字、拱门、PHARMACIE LES OLIVES 竖幅）、Goose 通道、A 大沥青路沿与电线。
A 小在 `world/short.js`：赭黄转角塔、灰石 Short Stairs（挡墙在东）、西侧 Lower Tunnels 拱廊（上层连拱、下层暗门）、绿棚红窗边楼、石板篦子与过街电线。上楼后西缘薄板接到 A 平台，往东进包点。
包点喷图 A(36,14)、B(-24,14)。
道具：Xbox、A 点淡绿铁箱、A 车（A 大近包点）、B 车、B 围栏、B 窗脚手架、匪口 Blue 集装箱、FRAGILE 白箱、包点棕榈。中路棕榈改为电线杆。中门 / A 门 / B 门贴金属门纹理（`kit.metalDoor`）。

## 出生点与镜头

`?spawn=`：t / garden / b2 / b / b1 / mid / midfar / ct / a / asmall / long / pit，共 12 个，全部带层高。
