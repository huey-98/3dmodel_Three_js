# 炙热沙城二（Dust2）场景 · 多层版

对应代码：`src/scenes/dust2/`。入口页 `index.html`，逻辑 `main.js`，世界在 `world.js` 与 `world/` 子目录。
场景是 CS2 经典地图 de_dust2 的可跑图还原：没有敌人与枪械，控制鲸尾女仆在多层地形上走动、跳箱、跳窗、钻下水道。

结构与层高不是拍脑袋画的：从 GitHub 上的 `gokayfem/dust2-shader` 仓库取回真实 `de_dust2.bsp`（GoldSrc v30，经典 1.6 布局），
用脚本解析全部地面面片（贴图过滤 sky/clip/trigger 后按连通域分带），得到各地面实测层高与区域边界，再按此重建：
匪家高台 → A 大逐级下行 → A 点；A 坑/中下桥洞是下沉层；B 点是架高平台；公寓是两层楼；下水道在街面以下。

## 尺度与坐标

单位米，X 向东、Z 向南（俯视图中 +Z 朝下），Y 向上。整图约 108×114 米（x -60..46，z -28..82）。
**地面不再是单一 0 米平面**：`layout.js` 用 `FLOORS`（可站楼板，带 top）、`STAIRS`（自动切踏步的楼梯）、
`MASS`（实心楼体）、`WALLS`（墙体）、`CEILS`（顶棚）五种矩形数据块拼出多层地形。

## 多层物理（physics.js）

关键约定：**地面高度按脚底感知**。

- `groundAt(world, x, z, r, feet)`：只认不高于脚底 + `STEP_UP`+0.06 的最高板顶。站在楼下不会被楼上地面抬走。
- `blockedAt(world, x, z, r, feet)`：solid 全高度挡人；platform 只在“顶面高于脚底+台阶余量 **且** 底面低于膝盖（脚底+0.55）”时挡人。
  这样架空猫道、公寓二层、B 平台下方都能正常穿行，而实心板（`deep`，底 -4.6）的侧壁在任何高度都挡人。
- `FLOORS.deep=true` 表示板下无房间（侧壁实心）；猫道、公寓二层、B 平台用真实 `bottom`。
- 楼梯由 `STAIRS` 自动切 0.34 米以内一步，靠 `STEP_UP` 直接走上去；跳高约 1.5 米（`JUMP_SPEED` 8.6 / `GRAVITY` 24）。
- 脚底低于 -6.2 视为坠出图外，自动回到当前出生点。
- `zoneAt(x, z, feet)` 匹配区域时同时要求脚底高度落在区域 `[y0, y1]` 内，同层的洞上下不会报错点。

## 门与窗口

`world/doors.js`：A 大门、中门、B 大门、猫道门、警家北门为对开木门（半开，中间可通行），全部带门槛高度 `sill`。
下水道南北口、公寓正门、A 大拱门、A 坑口、公寓二层外门用 `archGate()` 石拱框。
公寓西墙 z[8,12] 段是 `para: true` 矮女儿墙（顶 3.2，登记为 platform）：二层（脚底 4.0）可以跨出去跳窗落到 90°，一层则被挡住。

## 材质与贴图

`materials.js` 全部用 `canvasTex()` 运行时生成：沙岩砖墙、柏油街面（road，带中心线）、石板地面（cobble，包点/大院）、
洞内深色石墙、木箱、公寓地砖（apt）、猫道木板（wood）、蓝色金属、木门、木梁。
包点红圈字母 A/B 贴地块在 A(-39,68) 与 B(29,62) 地面。城垛（A 东墙、B 东墙、匪家南墙）与假窗在 `world/walls.js` 的 `facadeDetails()`。
棕榈树 14 棵按所在地面高度摆放；油桶、11 处灯火（下水道 3 处）、匪家红旗/警家蓝旗在 `world/props.js`。

## 出生点

`?spawn=`：t / long / a / pit / mid / bridge / corner / apartments / b / bback / tunnels / ct，共 12 个，全部带层高。

## 验证方法

1. `npm run build` 通过。
2. Node 无头冒烟：`.tmp_ref/test_dust2.mjs`（canvas 桩 + `@shared` loader hook）构建世界：725 meshes / 143 solids / 219 platforms / 7 rooms，
   12 个出生点 `groundAt` 全部命中期望层高。
3. 0.5 米栅格 BFS（转移规则：取“不高于当前脚底+1.5 的最高顶面”，落脚前做 `blockedAt` 检查）：
   匪家出发可达全部 21 个区域与 12 个出生点（含 A 坑、桥洞、猫道、公寓二层、下水道、B 后）。
   改动 `layout.js` 后务必重跑该脚本，连通性最容易在改门洞/台阶坐标时被破坏。
4. BSP 解析脚本：`.tmp_ref/analyze.mjs`、`.tmp_ref/render.mjs`、`.tmp_ref/trace.mjs`、`.tmp_ref/probe.mjs`（依赖 `.tmp_ref/de_dust2.bsp`）。
