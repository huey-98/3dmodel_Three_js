# 炙热沙城二（Dust2）场景 · CS2 走位版

对应代码：`src/scenes/dust2/`。入口页 `index.html`，逻辑 `main.js`，世界在 `world.js` 与 `world/` 子目录。
场景是 CS2 `de_dust2` 的可跑图还原：没有敌人与枪械，控制程序化建模的 CS T 方在多层地形上走动、跳箱、钻隧道。角色由共享模块 `src/shared/csT.js` 提供，其他地图也可复用。

布局按 CS2 官方雷达（匪家南、警家北、B 西北、A 东北）重排。坐标架为 X 向东、Z 向南、Y 向上，雷达的「上（北）」对应 z 小。
三条主路：后花园 → B2 → B 包点；暗道 → 中路 → 中门 → 沙地；A 门 → A 大 → A 包点。中门 / B 门为金属半开，A 门为金属对开。A 小只从中路上猫道。雷达黑色区域是封闭楼体。B1 洞口正对中门与 Xbox。
中路是 10 米宽的街（x[-5,5]）：西墙开 B1 洞口，东缘紧挨着架空猫道 x[5,22]（宽 17 m），猫道底下填实不留坠坑。
A 侧是两层结构，第一层(-1.0)现在是一条**通道**而不是一片广场：实楼底下打穿（x[15,22] z[19,24]，顶棚 4.4，两端石拱洞口），接悬空高架桥底下、再接楼前窄带，东西一条走道；西口出到警家广场条与沙地，警家只从南墙新开的口（x[12.2,14.6]）落到这条道上，东西两侧都封死。红框的北半（x[21,37.2] z[8,16]，把警家东门外那块广场一起算进来）统一填到 **+5.0** 做成能站人的台地，绿框那条 z[16,19] 不填——于是第二层连成一条天桥：东侧包点 → 台地 → 悬空桥面 → A 小楼梯，全程 +5.0，台地南脸与桥面就悬在巷子上方。第二层里 A 小楼梯北上落到桥面(+5.0，x[21.9,26.5] z[16,24.2])，这是 1 m 厚的悬空高架，宽 4.6 m 只比楼梯（x[22.2,26]）多一点，一列三根方墩（x=24.2，z=17.2/19.3/23.6）撑到地面；只有东沿立一道矮栏（北沿接台地、南沿接楼梯顶，都是实地，不再围），往东跳出桥沿落到巷子，往南就是 A 小楼梯顶。东侧包点西南原来的后坡已移除，下面改为与通道同高的完整巷子；上第二层改走 A 斜坡或天桥。A 包点与药房之间（x[26,42] z[26,35]）是另一栋 12 米高的楼。靠 A 大的北券楼体和 A 大北口石拱都已拆除。

## 多层物理（physics.js）

- `groundAt`：只认不高于脚底 + `STEP_UP`+0.06 的最高板顶（楼下不被楼上抬走）。
- `blockedAt`：solid 默认全高挡人，带 `bottom`/`top` 的只在该高度段挡人（悬空挡墙、门洞过梁、桥下通道）；platform 仅「顶高于脚底+余量 且 底低于膝盖」时挡人 → 猫道在中路高度挡人，跳上 Xbox 后可落猫道。
- 挡墙不能做成「又薄又悬空」：solid 厚度小于人物直径（2×`PERSON_R`=0.68 m）而上下都留缝时，人在旁边起跳会在腾空高度下通过水平判定，落回踏步就落在墙身里，此时四个方向的重叠判定全都成立 → 卡死动不了。A 小楼梯东侧那段原来是 `y[2.55,4.10]` 的悬空薄墙，已改成整条高；判据见验证第 5 条的 `trap_scan.mjs`。
- 反过来，桥墩这种「只该拦桥下、不该拦桥面」的构件要给 solid 传 `top`（高架的墩登记成 `solid(..., -Infinity, 桥底 4.0)`）：脚底超过 `top-STEP_UP` 就不再拦，桥面上横穿墩位照常走得过去。同一招反过来用就是**建筑底下打穿**：实楼拆成通道以北、以南两块全高 solid，跨在通道上方的那块登记成 `solid(..., 顶棚 4.4, Infinity)`——人在 -1.0 走得过去，跳不到 4.4 以上也进不了楼身里。
- `FLOORS` 里的楼板顶面彼此不要共面重叠：通道地面 x 取 [15,22]，正好与警家广场条（x1=15）、后巷（x0=22）和台地（z0=8）共边不共面。
- `deep: true` 的 `FLOORS` 一身二用，很适合做「上面能走、下面当墙」：顶面登记成可站的 platform，板底是 `VOID_Y`，所以在它下面那层走路的人会被板底当成墙挡住（+5 台地的南脸就是巷子的北墙），而它顶面之上的人照常走——台地接桥面、桥面接楼梯就是靠这一条连起来的。
- `STAIRS` 切 ≤0.34m 踏步（B1 旋转楼梯、A 小楼梯）；其余坡道在 `RAMPS`，按 ≤0.12m 细踏步登记物理、视觉渲染平滑楔体（`rampMesh`）。跳高约 1.5m。
- 下楼时脚底与地面差不超过 `STEP_UP`+0.06（一整级踏步）就直接吸附，走楼梯不会每级离地，也不会吞掉空格。
- 木箱 `crate` 只登记顶面 platform：地面挡人作掩体、跳起可落箱顶（Xbox 跳 A 小即靠此）。
- 要填掉楼下的空间就用 `FLOORS` 的 `deep` 条目（同时登记 volume 与 platform，platform 顶低于脚底就不挡人）；`MASS` 的 solid 不分高度，拿它填猫道底下会把整条猫道墙死。楼体自己那部分挡人由 `world/*.js` 调 `solid(x0,x1,z0,z1,bottom,top)` 按可见高度登记（转角塔、Lower Tunnels 拱廊、绿棚楼）。
- 脚底 < -6.2 坠出回出生点；`zoneAt` 同时匹配平面与脚底高度。

## 门与构件

`world/doors.js`：中门为半开金属门（`halfClosedDoor`，x=-4..4 / z=26，东扇闭、西扇斜开 30°留缝）；A 门是门厅南墙的一道金属对开（x=30..38 / z=50）；B 门为东墙金属半开（同中门，x=-9 / z[12,20]）。B 窗是墙缺口，无门扇。B 洞 / B 通入口为 `archGate()` 石拱（x=-30 z=24、x=-31 z=56）。A 大北口不再设门框。
半开门的可过缝隙受 AABB 限制：旋转门扇按铰链到门边登记成一整块矩形，中门真正过得去的位置只剩 x≈-0.5 那条约 0.3 m 宽的缝，贴着东扇西面过。
警家在 `world/ctspawn.js`：东向风化灰木拱门（望板顶、木梁格构）只留作立面——`closedSides()` 在拱洞里砌了一道板壁并登记 solid，望板顶本来就只作檐口、不登记可站面；延到北墙的顶棚改用同周边墙面的砂岩砖材，东侧凹口 x[21,26] z[4,8] 则以 A 平台同高（+5.0）、同石板材质填成不可穿过的实心楼体，补齐从 A 平台和沙城外圈看到的空洞。西边原来直连沙地的口子同样一道板墙封掉（x[10,10.38] z[4.3,16.1]）。剩下的出口是南墙 x[12.2,14.6] 的新开口（两侧留墙板、门楣与两根木柱），出去就是 A 通道西段。棚内沙地、北墙铁窗、悬挂灯；箱堆从南口前面挪到东北角（x≈18.7..19.7，z≈8.2..9.4）免得堵门。
