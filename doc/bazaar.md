# 荒漠迷城

入口 `src/scenes/bazaar/`。可走动的旧街区，中央是一座没有墙的绿篷棚子，棚下地面画着带红圈的红色 B。玩家是 `createCtOperator()` 生成的 CT 干员，出生在 `(0.8, 0, 7.2)`，面朝 -Z（朝向棚子）。镜头初始在 `(6.2, 13.2, 11.15)`，看向角色头顶，停在南楼北侧的广场上。

## 操作

WASD、方向键、Shift、空格、V、鼠标和滚轮与[架构文档](./architecture.md)相同。右上角「设置」可调移动速度和鼠标灵敏度。第一人称时隐藏干员，相机放在角色局部 `(0, 1.64, 0)`（护目镜高度）并平视当前面朝方向，之后身体朝向跟着水平视线。左键开火，R 键换弹。平移关闭。第三人称极角从 0.12 到 `π/2 - 0.04`，介于接近正上方和略高于水平之间。跟随目标在脚底上方 1.5 米。室外距离 3–42。

## 文件

| 文件 | 职责 |
| --- | --- |
| `main.js` | 场景、干员、跟随镜头、移动和棚内相机裁剪 |
| `operator.js` | CT 干员的几何、持枪姿势和走路 |
| `gun.js` | 第一人称开火、命中火花、换弹和 30 发弹夹 |
| `world.js` | 街区几何、碰撞矩形、篷布动画 |
| `materials.js` | 程序化贴图和材质包 `createBazaarKit()` |

## 场地

坐标以棚子为中心。`BOOTH` 为 X ∈ [-4.95, 5.25]、Z ∈ [-4.2, 5.05]、柱高 5.25。

- **地面**：150×150 沙黄大地砖，贴图每边 4 块砖、UV 重复 22 次，单块约 1.7 米。两处扁球体当地面积沙。
- **棚子**：四根木柱（碰撞）、canvas 画的红色 B（4.6×4.6，字母外有红圈，放在地面上方 0.045，用 polygon offset 减轻闪烁）。右前柱内侧有一只大木箱。顶是下垂的绿篷，带一块补丁和一块木板。篷布顶点按抛物面和局部凹陷下垂，贴图上有一块挖空的破洞。
- **左（-X）**：蓝色旧楼（原红楼加高一层，约 10.8），南端伸出阳台，阳台下留出货车通道。二楼东立面两扇大窗、一台空调外机；南立面阳台处一层高开口。三楼实墙无窗。
- **后（-Z）**：三栋高低不同的白楼薄条，贴在北侧。窗、一块绿色箭头招牌、水箱、卫星锅和天线在楼顶或立面上。
- **右（+X）**：沙黄长墙。西立面南端是一扇加宽加高的拱门，顶到接近屋檐；门北侧一扇跨两层的大窗。不再有空调外机和其他小窗。
- **南侧**：沙黄楼贴在原南墙位置，向南伸出约 8.2，没有窗户和米色线脚。中心向南开一个露天凹槽（宽约 11.4、深 6.5）。凹槽口的墙与东楼南沿齐平，高 2.25（略高于人物），墙左右各留 2.88 宽的通道。一辆浅色货车在西楼南侧，车头朝南楼，有碰撞盒。
- **其他**：电线杆、下垂电线、棚北缘一块橙色挂布、远处一排无阴影的方块楼、东楼西墙与南楼北墙夹角一只圆柱垃圾桶。
- **边界**：北、西、东仍是约 3.2 高的实墙；南侧改由南楼封住，楼后再挡一截。活动范围大约 X ∈ [-15.5, 17.0]、Z ∈ [-14.7, 12.4]，凹槽内可走到约 Z 18.9。墙和南楼都有碰撞。

`world.js` 开头注释写的是参考图布局：中央绿篷（正面红字 B）、左蓝楼、后白楼、右沙黄楼、南沙黄楼（露天凹槽），沙黄大地砖环绕。红字 B 的贴图 `markB` 贴在棚下地面。材质包里的 `panel`、`door`、`floor`、`pink` 没有被场景网格使用。

## 材质

`materials.js` 用固定种子的 `mulberry32` 画可重复的贴图：灰泥（粉、白、蓝、沙黄）、沙黄大地砖、木板、绿篷、橙布、木箱、树皮、棕榈叶、带圈红字 B、箭头招牌。墙上的重复尺度由 `world.js` 的 `makeBox` 处理：它按盒子各面的实际宽高重写 UV。粉、白、蓝带剥落；沙黄没有。粉灰泥仍在材质包里，场景网格不再使用。

玻璃是深色不透明材质，不是物理透射。叶子和破洞篷布用 `alphaTest` 抠边。

## 碰撞与棚内镜头

`createBazaar()` 返回 `{ group, solids, update }`。`solids` 来自墙、柱、箱子、货车、桶、南楼（含凹槽内的墙）和场地边界。地面、篷布、窗户不挡人。重叠测试与别墅相同，角色半径 0.32。地面高度恒为 0，跳跃是唯一的垂直运动。

棚内范围写在 `main.js` 的 `ROOM`：X ∈ [-4.55, 4.85]，Z ∈ [-3.8, 4.65]，高度 0.4–4.9。下面的距离限制只在第三人称、且人在这个水平范围内时生效：

- 相机距离改成 1.6–5.2
- 沿当前视线用 `maxRayInside` 计算离开棚子盒子的距离，再把相机拉回到该距离减 0.12，且不少于 0.6

这样在棚里旋转时相机会停在柱子和篷顶之内，而不是穿进周围房屋。走出棚子后距离限制恢复为 3–42。

## 动画

`world.update(elapsed)` 驱动绿篷和橙布：按各自基准顶点做竖直正弦位移，布料用 UV 的 V 作为权重，上沿几乎不动、下沿摆得更多。

每帧对这些几何体 `computeVertexNormals()`。干员走路由 `operator.update(dt, moving)` 处理，没有划船参数。

## 玩家

`createCtOperator()` 只在本场景使用。几何体运行时用盒子、球体和圆柱拼成，约 1.88 米高：深蓝制服、炭黑防弹衣、胸前和两袖的 CT 牌、带蓝色护目镜的头盔、护膝、战斗靴，步枪横在胸前。面朝局部 +Z。外层 `group` 管位置、朝向和跳跃；胸腔组只做呼吸，以及走路时的轻微扭转。

`update(dt, moving)` 少传 `moving` 时按停下处理。行走相位速度 `dt * 9`，摆幅目标 0.62，左右腿反相，后腿屈膝，脚踝把鞋底扳平，避免靴底插进地面。步枪和手臂保持持枪姿势，不随步态甩开。停下时胸腔有很小的呼吸起伏。返回 `{ group, update }`。多出来的参数会被忽略，这个角色没有划船坐姿。

开火只在本场景的第一人称里。`createCarbine()` 监听画布左键和 R 键，第三人称下直接忽略。弹夹 30 发，开局装满。每发间隔至少 0.09 秒；打空后再按左键只有空仓声，不发射。R 在弹夹未满时开始换弹，1.65 秒后重新装满，换弹途中不能开枪。没有备用弹药上限。射线从相机前方 0.45 米沿视线打到 `world.group`，最远 48 米，命中处有一小团火花。右下角 `#ammo` 只在第一人称显示剩余弹量，换弹时写成「换弹」加当前余数。别墅和女仆展示页不创建这套枪。
