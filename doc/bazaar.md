# 荒漠迷城

入口 `src/scenes/bazaar/`。可走动的旧街区，中央是一座没有墙的绿篷棚子，棚下地面画着带红圈的红色 B。玩家是 [`createPerson`](./shared.md) 生成的简易小人，出生在 `(0.8, 0, 7.2)`，面朝 -Z（朝向棚子）。镜头初始在 `(6.2, 13.2, 11.15)`，看向角色头顶，停在南楼北侧的广场上。

## 操作

WASD、方向键、Shift、空格、V、鼠标和滚轮与[架构文档](./architecture.md)相同。第一人称时隐藏小人，相机放在角色局部 `(0, 1.55, 0)` 并平视当前面朝方向，之后身体朝向跟着水平视线。平移关闭。第三人称极角从 0.12 到 `π/2 - 0.04`，介于接近正上方和略高于水平之间。室外距离 3–42。

## 文件

| 文件 | 职责 |
| --- | --- |
| `main.js` | 场景、小人、跟随镜头、移动和棚内相机裁剪 |
| `world.js` | 街区几何、碰撞矩形、篷布动画 |
| `materials.js` | 程序化贴图和材质包 `createBazaarKit()` |

## 场地

坐标以棚子为中心。`BOOTH` 为 X ∈ [-4.95, 5.25]、Z ∈ [-4.2, 5.05]、柱高 5.25。

- **地面**：150×150 沙黄大地砖，贴图每边 4 块砖、UV 重复 22 次，单块约 1.7 米。两处扁球体当地面积沙。
- **棚子**：四根木柱（碰撞）、canvas 画的红色 B（4.6×4.6，字母外有红圈，放在地面上方 0.045，用 polygon offset 减轻闪烁）。右前柱内侧有一只大木箱。顶是下垂的绿篷，带一块补丁和一块木板。篷布顶点按抛物面和局部凹陷下垂，贴图上有一块挖空的破洞。
- **左（-X）**：粉色旧墙，南端伸出阳台，阳台下留出货车通道。墙面有一列窗和空调外机。
- **后（-Z）**：三栋高低不同的白楼薄条，贴在北侧。窗、一块绿色箭头招牌、水箱、卫星锅和天线在楼顶或立面上。
- **右（+X）**：蓝色长墙。西立面南端是一扇加宽加高的拱门，顶到接近屋檐；门北侧一扇跨两层的大窗。不再有空调外机和其他小窗。
- **南侧**：沙黄楼贴在原南墙位置，向南伸出约 8.2，没有窗户和米色线脚。中心向南开一个露天凹槽（宽约 11.4、深 6.5）。凹槽口的墙与蓝楼南沿齐平，高 2.25（略高于人物），墙左右各留 2.88 宽的通道。一辆浅色货车在红楼南侧，车头朝南楼，有碰撞盒。
- **其他**：电线杆、下垂电线、棚北缘一块橙色挂布、远处一排无阴影的方块楼、蓝楼西墙与南楼北墙夹角一只圆柱垃圾桶。
- **边界**：北、西、东仍是约 3.2 高的实墙；南侧改由南楼封住，楼后再挡一截。活动范围大约 X ∈ [-15.5, 17.0]、Z ∈ [-14.7, 12.4]，凹槽内可走到约 Z 18.9。墙和南楼都有碰撞。

`world.js` 开头注释写的是参考图布局：中央绿篷（正面红字 B）、左粉墙、后白楼、右蓝墙、南沙黄楼（露天凹槽），沙黄大地砖环绕。红字 B 的贴图 `markB` 贴在棚下地面。材质包里的 `panel`、`door`、`floor` 没有被场景网格使用。

## 材质

`materials.js` 用固定种子的 `mulberry32` 画可重复的贴图：灰泥（粉、白、蓝、沙黄）、沙黄大地砖、木板、绿篷、橙布、木箱、树皮、棕榈叶、带圈红字 B、箭头招牌。墙上的重复尺度由 `world.js` 的 `makeBox` 处理：它按盒子各面的实际宽高重写 UV。粉、白、蓝带剥落；沙黄没有。

玻璃是深色不透明材质，不是物理透射。叶子和破洞篷布用 `alphaTest` 抠边。

## 碰撞与棚内镜头

`createBazaar()` 返回 `{ group, solids, update }`。`solids` 来自墙、柱、箱子、货车、桶、南楼（含凹槽内的墙）和场地边界。地面、篷布、窗户不挡人。重叠测试与别墅相同，角色半径 0.32。地面高度恒为 0，跳跃是唯一的垂直运动。

棚内范围写在 `main.js` 的 `ROOM`：X ∈ [-4.55, 4.85]，Z ∈ [-3.8, 4.65]，高度 0.4–4.9。下面的距离限制只在第三人称、且人在这个水平范围内时生效：

- 相机距离改成 1.6–5.2
- 沿当前视线用 `maxRayInside` 计算离开棚子盒子的距离，再把相机拉回到该距离减 0.12，且不少于 0.6

这样在棚里旋转时相机会停在柱子和篷顶之内，而不是穿进周围房屋。走出棚子后距离限制恢复为 3–42。

## 动画

`world.update(elapsed)` 驱动绿篷和橙布：按各自基准顶点做竖直正弦位移，布料用 UV 的 V 作为权重，上沿几乎不动、下沿摆得更多。

每帧对这些几何体 `computeVertexNormals()`。小人走路动画由 `person.update(dt, moving)` 处理，没有划船参数。
