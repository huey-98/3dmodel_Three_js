# 荒漠迷城

入口 `src/scenes/bazaar/`。可走动的旧街区，中央是一座没有墙的绿篷棚子，棚下地面画着带红圈的红色 B。玩家是 `createCtOperator()` 生成的 CT 干员，出生在 `(1.2, 0, 10.8)`，面朝 -Z（朝向棚子）。镜头初始在 `(9.3, 13.2, 16.73)`，看向角色头顶，停在南楼北侧的广场上。

## 操作

WASD、方向键、Shift、空格、V、鼠标和滚轮与[架构文档](./architecture.md)相同。右上角「设置」可调移动速度、鼠标灵敏度和第一人称视野（默认 90°，范围 70°–110°）。第一人称时隐藏干员身体，相机放在角色局部 `(0, 1.64, 0)`（眼睛高度，也就是护目镜中线；人物整体缩放 0.9 后世界高度约 1.48）并平视当前面朝方向，之后身体朝向跟着水平视线。画面右下会画出当前手里的武器。1 步枪、2 手枪、3 匕首，左键使用，R 键给枪换弹。平移关闭。第三人称极角从 0.12 到 `π/2 - 0.04`，介于接近正上方和略高于水平之间。跟随目标在脚底上方 1.35 米。室外距离 3–63。

## 场地

坐标以棚子为中心。布局按 `MAP_SCALE = 1.5` 只放大水平方向，层高、窗台和跳板高度不变。`BOOTH` 世界范围为 X ∈ [-7.43, 7.88]、Z ∈ [-6.3, 7.58]、柱高 5.25。

- **地面**：225×225 沙黄大地砖，贴图每边 4 块砖、UV 重复 33 次，单块约 1.7 米。两处扁球体当地面积沙。
- **棚子**：四根木柱（碰撞）、canvas 画的红色 B（约 6.9×6.9，字母外有红圈，放在地面上方 0.045，用 polygon offset 减轻闪烁）。右前柱内侧有一只大木箱。顶是下垂的绿篷，带一块补丁和一块木板。篷布顶点按抛物面和局部凹陷下垂，贴图上有一块挖空的破洞。
- **左（-X）**：蓝色旧楼（原红楼加高一层，约 10.6），南端伸出阳台，阳台顶约 3.7，可站立。二楼挖空，浅黄地面和内壁，一张木桌和靠西墙的柜子；可从阳台南侧开口走进二楼。东立面两扇开口大窗、一台空调外机；南立面阳台处一层高开口，都没有玻璃，能看见室内。一楼和三楼仍是实心。
- **后（-Z）**：三栋高低不同的白楼薄条，贴在北侧。窗、一块绿色箭头招牌、水箱、卫星锅和天线在楼顶或立面上。
- **右（+X）**：沙黄楼，空心可进。西立面南端是一扇加宽加高的拱门（无玻璃，可走进小卖部）；门北侧一扇开口大窗（窗台约 0.78，洞高约 2.48，无玻璃），可看见室内，也可跳上窗台再进入。楼里是小卖部：东内墙一只货架（约 Z 5.0–12.1，避开窗口），南内墙一只收银台（不挡门）。顶上三盏灯。不再有空调外机和其他小窗。
- **南侧**：沙黄楼贴在原南墙位置，向南伸出约 12.3，没有窗户和米色线脚。中心向南开一个露天凹槽（宽约 17.1、深 9.8）。凹槽口的墙与东楼南沿齐平，高 2.25（略高于人物），墙左右各留约 4.3 宽的通道。一辆浅色货车停在西楼阳台南侧通道里，车头朝南，车尾与阳台之间留约 1.7 米空地。车身东侧有一只约 1.05 高的木箱当跳板，可先跳上箱子再跳上车顶（约 2.35），再从车顶助跑跳上二楼阳台。
- **其他**：电线杆、下垂电线、棚北缘一块橙色挂布、远处一排无阴影的方块楼、东楼西墙与南楼北墙夹角一只圆柱垃圾桶。
- **边界**：北、西、东仍是约 3.2 高的实墙；南侧改由南楼封住，楼后再挡一截。活动范围大约 X ∈ [-23.3, 25.5]、Z ∈ [-22.1, 18.6]，凹槽内可走到约 Z 28.4。墙和南楼都有碰撞。

`world.js` 开头注释写的是参考图布局：中央绿篷（正面红字 B）、左蓝楼、后白楼、右沙黄楼（小卖部）、南沙黄楼（露天凹槽），沙黄大地砖环绕。红字 B 的贴图 `markB` 贴在棚下地面。材质包里的 `panel`、`door`、`pink` 没有被场景网格使用。`floor` 铺在小卖部室内。

## 材质

`materials.js` 用固定种子的 `mulberry32` 画可重复的贴图：灰泥（粉、白、蓝、沙黄）、沙黄大地砖、木板、绿篷、橙布、木箱、树皮、棕榈叶、带圈红字 B、箭头招牌。墙上的重复尺度由 `world.js` 的 `makeBox` 处理：它按盒子各面的实际宽高重写 UV。粉、白、蓝带剥落；沙黄没有。粉灰泥仍在材质包里，场景网格不再使用。`cream` / `creamFloor` 是浅黄纯色，用在西楼二楼室内。

玻璃是深色不透明材质，不是物理透射。叶子和破洞篷布用 `alphaTest` 抠边。

## 碰撞与棚内镜头

`createBazaar()` 返回 `{ group, solids, platforms, rooms, update }`。`solids` 来自墙、柱、棚内大箱、桶、南楼（含凹槽内的墙）、东楼外墙（拱门洞和开口窗除外）、西楼外墙（东窗洞和南阳台开口除外）、二楼桌柜、小卖部货架和收银台，以及场地边界，从任何高度都挡住水平移动。东楼不再是实心块；西墙只在拱门两侧和窗口以外设碰撞。西楼一楼仍不能走进去。`platforms` 是货车顶、车旁跳板箱、西楼二楼地面和南阳台（约 3.7），以及小卖部窗台（约 0.78）：脚下低于顶面约 0.35 时当墙挡，够高则可走上去。地面、篷布、开口窗和敞开的拱门不挡人。重叠测试与别墅相同，角色半径约 0.29。地面高度默认 0；站在平台 AABB 上时取最高的 `top`。从平台走出去会下落。重力 24、起跳速度 8.6，地面起跳约 1.54 高，所以能跳上小卖部窗台；上车要借跳板，再从车顶跳上西楼二楼阳台。

`rooms` 有三处：棚内 X ∈ [-6.83, 7.28]，Z ∈ [-5.7, 6.98]，高度 0.4–4.9；东楼小卖部室内（墙厚以内）；西楼二楼室内（墙厚以内，不含阳台）。下面的距离限制只在第三人称、且人在某个房间水平范围内时生效：

- 相机距离改成 2.4–7.8
- 沿当前视线用 `maxRayInside` 计算离开当前房间盒子的距离，再把相机拉回到该距离减 0.12，且不少于 0.6

这样在棚里或小卖部里旋转时相机会停在房间之内，而不是穿进周围房屋。走出房间后距离限制恢复为 3–63。

## 动画

`world.update(elapsed)` 驱动绿篷和橙布：按各自基准顶点做竖直正弦位移，布料用 UV 的 V 作为权重，上沿几乎不动、下沿摆得更多。

每帧对这些几何体 `computeVertexNormals()`。干员走路由 `operator.update(dt, moving)` 处理，没有划船参数。

## 玩家

`createCtOperator()` 只在本场景使用。几何体运行时用盒子、球体和圆柱拼成，再整体缩放 0.9，约 1.69 米高：深蓝制服、炭黑防弹衣、胸前和两袖的 CT 牌、带蓝色护目镜的头盔、护膝、战斗靴，一支 M4A1-S 横在胸前：深色枪托，橙色缓冲管，灰色上下机匣和深色提把，提把一侧有红色标记，顶部有橙色拉机柄，深色方盒护木上有黑色横条，顶上有导气轨，轨顶分节，轨内有细导气管通向准星，准星前后的枪管是橙色，枪口是黑色圆筒消音器，弹匣是直的。面朝局部 +Z。外层 `group` 管位置、朝向和跳跃；胸腔组只做呼吸，以及走路时的轻微扭转。

`update(dt, moving)` 少传 `moving` 时按停下处理。行走相位速度 `dt * 9`，摆幅目标 0.62，左右腿反相，后腿屈膝，脚踝把鞋底扳平，避免靴底插进地面。步枪和手臂保持持枪姿势，不随步态甩开。停下时胸腔有很小的呼吸起伏。返回 `{ group, update }`。多出来的参数会被忽略，这个角色没有划船坐姿。

开火只在本场景的第一人称里。`createCarbine()` 在第三人称下忽略左键，并隐藏手里的武器。武器和手画在单独的近景里：主场景画完后清掉深度再画这层，所以贴墙时枪和手不会扎进墙里。视野用设置里的第一人称角度，默认 90°。

步枪按 M4A1-S 参考造型来搭：炭灰上下机匣与一体化提把（两侧立边、后端觇孔照门），提把侧面红标；右侧抛壳窗、助推钮，左侧快慢机；delta 环衔接护木，条纹圆筒护木与两侧散热缝，护木顶导气轨与内藏导气管；外露橙段枪管、A 形准星座，消音器前有金属箍与 body 上的通气槽、封闭式帽；伸缩托、橙缓冲管，指槽握把，略弯条纹弹匣带底板和防潮绳；橙色扳机与拉机柄。枪身靠在画面右下角，略微向下，并有约 2° 的右倾。画面里大约能看到枪身前三分之二，握把和右手在画面外。左手手掌托住护木，露出的一小段前臂向画面左侧偏。开火时火焰从枪口喷出。枪口不挡住屏幕中心的准星。手枪放在画面右下角，枪身放平、不侧倾；加长枪管藏在套筒前方的整段圆柱消音器里，消音器后缘与套筒前面齐平、外径与套筒相当，附环一带有穿孔饰圈，中段箍环与封闭帽。枪管平着朝前。右手握握把并扣扳机，左手并在右侧手上一起托住。手枪只画到手，不画前臂。匕首是双刃尖刀：刀身从护手向刀尖对称收窄，断面呈菱形，中间起脊；护手横在刃根，两端有圆头；握柄包皮，上面有三道金属环，末端是圆柄头。匕首停在画面右下角、靠近屏幕边缘。刀身与地面大约成 36°，刀尖高于刀柄，朝前上方，但仍低于准星；刀刃朝向外侧并略向下。右手握在刀柄中后部，手指包住刀柄，拇指贴在一侧，手腕略内收，前臂向下伸出画面。左键是刺击，大约 0.48 秒：前 0.1 秒手腕后拉、刀身略抬起；接着快速向前刺出，约 0.2 秒刀尖伸到准星附近；0.26 秒后收回，结束前会略微过冲再回到持刀位置。走动时枪和手有轻微晃动。切枪时武器先下沉再抬起，手指松开再握紧。

手是分段的手指，戴深色皮革手套，腕部有一段布料护腕。步枪和匕首的护腕后面接着前臂，手枪没有前臂。手枪开火时右手食指扣扳机。换弹时右手下压弹匣再送回；步枪接着由左手把顶部拉机柄向后带一下，手枪则拉动套筒，左手跟着弹匣下压。

`1` / `2` / `3` 切换武器，两把枪各自记住弹匣和备弹。步枪弹匣 30、备弹 90，按住左键连发，间隔 0.09 秒。手枪弹匣 12、备弹 36，只能单点，间隔 0.2 秒。换弹从备弹里补进弹匣，备弹不够就只补剩下的；备弹为 0 时不能换。弹匣打空且还有备弹时自动换弹，也可以按 R 提前换。步枪 1.65 秒，手枪 1.3 秒，换弹途中不能开枪，匕首不换弹。瞄准射线从相机前方 0.35 米沿视线打到 `world.group`，枪最远 72 米。枪口火焰在近景里喷出：根部偏白，中段橙黄，尖端橙红，大约显示两帧后消失。一条细长曳光从枪口以 120 米/秒飞向命中点。命中处是弹孔和碎屑，3 秒后消失。匕首在刀尖伸到最远时（点击后约 0.2 秒）沿视线射线最远 2.1 米，命中墙面留下一道划痕，同样 3 秒后恢复。刺击间隔 0.48 秒。

界面只在第一人称出现。准星是屏幕中心的绿色十字，正中有一个圆点，移动、跳跃和开火时四条线张开，圆点保持不动。左下角 `#vitals` 是血量和护甲；目前没有受伤来源，两项都保持 100。右下角 `#ammo` 是武器简图、当前弹匣和备弹，换弹时在简图下有一条从空到满的进度条。步枪简图里缓冲管和枪管涂成橙色。别墅和女仆展示页不创建这套武器。
